# Contributing

Run the tests with `python -m unittest`.

## Conventions

- Timestamps are stored in UTC as ISO 8601 with a `Z` suffix and whole seconds,
  for example `2026-03-01T09:30:00Z`. No local time, no offsets, no fractions.
- `schema.json` is generated by `python gen_schema.py` from `notes.FIELDS`. The
  mobile client reads it, so it has to match the fields the store writes.
